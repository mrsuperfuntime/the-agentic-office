# Sales Office

Manages all sales operations including pipeline, forecasting, and customer acquisition.

## Office Structure

- **Office Manager**: Sales Director Agent
- **Account Executives Team**: Handles high-value deals
- **Sales Development Team**: Prospecting and lead generation
- **Sales Operations Team**: Support and enablement

## API Endpoints

- `GET /health` - Service health
- `GET /manager` - Manager info
- `POST /handle-request` - Handle inter-office requests
