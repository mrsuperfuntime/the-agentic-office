# HR Office

Manages human resources including recruitment, employee management, and payroll.

## Office Structure

- **Office Manager**: HR Director Agent
- **Recruitment Team**: Hiring and talent acquisition
- **Employee Relations Team**: Employee support and development
- **Payroll Team**: Compensation and benefits administration

## API Endpoints

- `GET /health` - Service health
- `GET /manager` - Manager info
- `POST /handle-request` - Handle inter-office requests
