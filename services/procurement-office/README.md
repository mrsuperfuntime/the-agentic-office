# Procurement Office

Manages vendor relationships, supply chain, and procurement operations.

## Office Structure

- **Office Manager**: Procurement Manager Agent
- **Vendor Management Team**: Vendor relationships and negotiations
- **Purchase Orders Team**: PO processing and fulfillment
- **Supply Chain Team**: Logistics and delivery coordination
- **Cost Analysis Team**: Pricing analysis and savings optimization

## API Endpoints

- `GET /health` - Service health
- `GET /manager` - Manager info
- `POST /handle-request` - Handle inter-office requests
