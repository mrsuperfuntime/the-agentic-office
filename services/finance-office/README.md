# Finance Office

Manages financial operations, budgeting, and reporting.

## Office Structure

- **Office Manager**: Finance Director Agent
- **Accounting Team**: Ledger and transaction management
- **Financial Planning Team**: Budgeting and forecasting
- **Analysis & Reporting Team**: Financial analysis and reports
- **Audit Team**: Compliance and audit

## API Endpoints

- `GET /health` - Service health
- `GET /manager` - Manager info
- `POST /handle-request` - Handle inter-office requests
