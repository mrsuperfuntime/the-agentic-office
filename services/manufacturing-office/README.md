# Manufacturing Office

Manages production, quality, and inventory operations.

## Office Structure

- **Office Manager**: Manufacturing Director Agent
- **Production Planning Team**: Scheduling and resource allocation
- **Quality Assurance Team**: Quality control and compliance
- **Inventory Team**: Stock management and logistics
- **Operations Team**: Floor management and efficiency

## API Endpoints

- `GET /health` - Service health
- `GET /manager` - Manager info
- `POST /handle-request` - Handle inter-office requests
