# Customer Service Office

Manages customer support, satisfaction, and feedback.

## Office Structure

- **Office Manager**: Customer Service Manager Agent
- **Support Team**: Direct customer interaction and issue resolution
- **Quality Assurance Team**: QA and process improvement
- **Customer Success Team**: Proactive customer support
- **Feedback Analysis Team**: Sentiment and trend analysis

## API Endpoints

- `GET /health` - Service health
- `GET /manager` - Manager info
- `POST /handle-request` - Handle inter-office requests
